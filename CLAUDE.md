# CLAUDE.md

Working notes for this repo. Short on purpose — see each folder's README for
how a given script actually works.

## How the pages are built

Every published page is a **single self-contained HTML file** generated by a
Python script (`build_site.py`, `build_collection.py`, and the Tarkov builder),
committed to that folder's `site/`, and assembled by
`.github/workflows/pages.yml`. There is **no bundler, no npm, no build step** —
the Python writes HTML with inline `<style>` and inline `<script>`.

As of now the pages load **no external JavaScript at all**. The only third-party
requests are Google Fonts (one stylesheet) and images from Alamo's, TMDB's and
Steam's CDNs. Anything added below would be the first external script.

## Web UI libraries to consider

Noted for when a page wants motion or a richer feel.

| Library | What it is | Licence | Needs |
|---|---|---|---|
| [Lenis](https://github.com/darkroomengineering/lenis) | Lightweight smooth-scroll | MIT | Nothing — framework-agnostic, drops in as a script tag |
| [GSAP](https://github.com/greensock/GSAP) | Animation platform | Free for commercial use; **all plugins now free**, including the formerly paid SplitText and MorphSVG | Nothing — script tag |
| [Vanta](https://github.com/tengbao/vanta) | Animated 3D/WebGL backgrounds | MIT | **three.js or p5.js** as a peer dep, per effect |
| [react-bits](https://github.com/DavidHDev/react-bits) | Animated, customisable React components | **MIT + Commons Clause** | **React**, plus a build step; installed by shadcn/jsrepo CLI or copy-paste |

### Two things to know before reaching for these

**react-bits is the odd one out.** It needs React and a toolchain, and these
pages are vanilla HTML emitted by Python. Using it directly would mean adding a
bundler to a repo that has deliberately avoided one. Its value here is as a
**reference** — the components are copy-paste source, so an effect can be read
and ported to plain CSS/JS. Note also that Commons Clause is not plain MIT: it
bars *selling* the software. Irrelevant for personal pages, worth knowing.

**Vanta pulls in three.js**, which is heavy next to pages that are currently
69–290 KB of self-contained HTML. Fine for a hero background if that is the
point; not free.

Lenis and GSAP are the two that fit the current setup with no structural
change — both are a single script tag and neither assumes a framework.

## Conventions worth keeping

- **Stdlib-only Python.** None of the builders take a third-party dependency.
- **Generated output is committed** (`site/`, `cache/`, `ci-state/`) because the
  runners are ephemeral and the pages are served from the repo.
- **A quiet run prints nothing.** Silence means "nothing new", which is what
  makes the daily schedules safe to ignore until they speak up.
